# Linux Practice Challenges

A collection of hands-on challenges for learning Linux command-line skills.

## Available Challenges

| ID | Challenge | Level |
|---|---|---|
| 01 | Linux Navigation | Beginner |

## How to Use

1. Read each challenge carefully.
2. Try to solve the tasks in your terminal.
3. Use `man <command>` to consult Linux documentation.
4. Verify your results before marking tasks as completed.

## Guidelines

- Practice in authorized environments.
- Understand each command before executing it.
- Try to solve challenges before checking solutions.
