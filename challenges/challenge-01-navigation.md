
# Challenge 01 — Linux Navigation

## Objective
Practice basic Linux filesystem navigation.

## Tasks

### Task 1 — Current Directory
Use a command to display your current directory.

### Task 2 — List Files
Display all files, including hidden files, with detailed information.

### Task 3 — Change Directory
Navigate to `/tmp`, then return to your home directory.

### Task 4 — Create a Directory
Inside `/tmp`, create a directory named `linux-practice`.

### Task 5 — Verify
Display the contents of `/tmp` and verify that `linux-practice` exists.

## Rules
- Try to solve each task without looking up the solution.
- Read the command documentation using `man` when needed.
- Practice only in directories where you have permission.
