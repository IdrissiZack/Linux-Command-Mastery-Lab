# Linux Command Mastery Lab

A beginner-friendly, hands-on project for learning Linux command-line fundamentals through explanations and practical challenges.

## Objectives

- Understand essential Linux commands.
- Practice filesystem navigation.
- Learn by solving practical challenges.
- Build safe command-line habits.

## Project Structure

- `modules/` — Lessons and command explanations.
- `challenges/` — Practical exercises to test your knowledge.

## Getting Started

1. Open a lesson inside `modules/`.
2. Read the explanation carefully.
3. Open the related challenge inside `challenges/`.
4. Try the exercises in your own Linux terminal.
5. Use `man <command>` to read the official manual when needed.

## Current Topics

- Filesystem navigation: `pwd`, `ls`, `cd`, `mkdir`.

## Who Is This For?

Beginners who want to learn Linux step by step through practice.

## Safety

Practice only on systems and files you own or are authorized to use.
